# 🇹🇼 台灣投資組合蒙地卡羅模擬器 (Taiwan Portfolio Visualizer Monte Carlo)

專為台灣投資人、存股族與 FIRE 退休規劃者量身打造的**專業級蒙地卡羅投資組合模擬系統**。

---

## 🌟 核心特色

### 1. 台美雙市場在地化配置
- **台股精選標的**：元大台灣50 (0050)、富邦台50 (006208)、高股息 (0056 / 00878 / 00919)、富邦中小型 (0051)、台幣活存/定存。
- **美股與全球標的**：標普500 (VOO / SPY)、那斯達克100 (QQQ)、全球股市 (VT)、美國長天期公債 (TLT / 00679B)、全球綜合債 (BND / BNDW)、黃金 (GLD)。
- **一鍵經典組合**：
  - 台灣存股雙核心 (50% 0050 + 50% 00878)
  - 經典股債平衡 60/40
  - 柏格頭全球三基金 (VT + 0050 + BNDW)
  - 橋水全天候防禦組合 (All Weather)
  - FIRE 退休穩健現金流組合
  - 積極科技成長組合 (QQQ + 0050)

### 2. 扣除通膨與實質購買力分析 (重點功能)
- **一鍵切換「實質購買力 (已扣除通膨)」vs「名目金額 (未扣通膨)」**：所有圖表、分位數曲線與明細表即時換算。
- **靈活通膨模型**：支援自訂固定年通膨率（預設 2.0%）或 2000-2025 年歷史 CPI 真實抽樣。
- **實質購買力折損計算機**：即時試算在長期通膨下貨幣價值的折損比例。

### 3. 多元現金流與 FIRE 退休提領法則
- **定期定額累積期**：每月/每年定期投入，支援每年隨薪資/通膨調升投入金額。
- **退休提領期 (FIRE)**：
  - 固定實質金額 (經典 4% 法則每年通膨調整)
  - 固定淨值比例提領
  - Guyton-Klinger 動態護欄法則 (資本保全與繁榮規則)
  - 上下限保護提領 (-5% ~ +5%)

### 4. 專業量化指標與圖表
- **扇形百分位走勢圖**：第 10 (最悲觀)、25、50 (中位數)、75、90 (最樂觀) 百分位數走勢，支援 30 條隨機波動軌跡抽樣。
- **終值資產分佈直方圖**：直觀呈現各累積資產區間的機率。
- **逐年資產與現金證明細表**：同步列出實質與名目數據。
- **下檔風險與回撤分析**：最大回撤 (Max Drawdown) 與最差歷史考驗。
- **報表匯出**：一鍵下載 UTF-8 with BOM CSV 報表，支援直接列印/另存 PDF。

## 📐 演算法與金融模型架構

1. **幾何布朗運動與多資產相關性模型 (Parametric Cholesky Decomposition)**：
   - 依據各資產歷史年化報酬率 $\mu$、波動度 $\sigma$ 與資產間相關係數矩陣 $\mathbf{C}$ 建立協方差矩陣 $\boldsymbol{\Sigma}$。
   - 透過 Cholesky 下三角分解 $\boldsymbol{\Sigma} = \mathbf{L}\mathbf{L}^T$ 生成多維度相關常態隨機變數 $Z_{\text{corr}} = \mathbf{L}Z$：

   $$\text{Return}_i = \exp\left[\left(\mu_i - \frac{1}{2}\sigma_i^2\right) + \sigma_i Z_{\text{corr}, i}\right] - 1$$

2. **歷史真實重抽樣模型 (Historical Bootstrap)**：
   - 隨機自 2000 ~ 2025 年台美市場歷史年度總報酬與台灣 CPI 通膨資料庫進行跨資產同步抽樣，完整保留股債連動性，並捕捉科技泡沫、金融海嘯與通膨升息之極端肥尾風險。

3. **實質購買力通膨折現模型 (Fisher Inflation Adjustment)**：
   - 累積通膨係數：

   $$\text{CumInflation}_t = \prod_{k=1}^{t} (1 + \text{Inflation}_k)$$

   - 實質購買力資產終值：

   $$\text{Real Wealth}_t = \frac{\text{Nominal Wealth}_t}{\text{CumInflation}_t}$$
